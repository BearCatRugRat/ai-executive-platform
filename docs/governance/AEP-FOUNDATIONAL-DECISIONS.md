# AEP Foundational Decisions

- AEP-FD-001: AEP is the umbrella platform; Collector Intelligence is the flagship domain application.
- AEP-FD-002: Repositories are siblings, not nested.
- AEP-FD-003: The Executive Command Center is the daily entry point.
- AEP-FD-004: Morning intelligence spans all registered applications.
- AEP-FD-005: Shared services are built once and consumed through stable contracts.
- AEP-FD-006: Domain authority remains within each domain application's governed records.
- AEP-FD-007: AI may recommend and prepare changes but cannot silently alter authoritative truth.
- AEP-FD-008: Existing Collector work will be preserved and integrated incrementally, not rewritten wholesale.
- AEP-FD-009 (2026-08-03): This record's three-application portfolio (Collector Intelligence, Myers Wolin IP Intelligence, Prediction Intelligence) is authoritative for what counts as a Domain Application. `collector-intelligence-engine`'s governance API additionally tracks a second tier - "Command Center Areas" (Personal Finance, Myers Family, Development/Platform status, Health, Home Technology, Travel, Research Platform) - things the Command Center shows a button and live status for, without the dedicated engineering investment (own database, API, module contract) a Domain Application gets. An area may graduate to a Domain Application later; that is a deliberate decision, not automatic. Lottery Intelligence Research is the current active project inside Prediction Intelligence, not a competing name for it - lottery is a subset of prediction. Full reconciliation: `collector-intelligence-engine/docs/architecture/0003-shared-platform-and-domain-boundaries.md`, Addendum (2026-08-03, part 2). Before either repository finalizes a platform-level decision (domain list, module contracts, shared-service boundaries), check both repositories' governance docs first.
