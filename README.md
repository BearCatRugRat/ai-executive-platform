# AI Executive Platform

The AI Executive Platform (AEP) is the umbrella operating environment for Brian Myers' professional intelligence applications.

## Applications

- Collector Intelligence Platform — flagship collectible intelligence application.
- Myers Wolin IP Intelligence Platform — patent, prosecution, litigation, knowledge, and firm workflow platform.
- Prediction Intelligence Platform — lottery research, prediction markets, forecasting, simulation, and backtesting.

## Repository relationship

This repository is a sibling of `collector-intelligence-engine`; it does not replace or nest the existing repository. Shared platform services are developed here. Domain applications remain independently governed modules and may later be integrated through stable module contracts.
